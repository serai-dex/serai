# Serai Economic Security Pallet

This pallet tracks the economic security of Serai, as relevant to the
[Economics specification](/spec/Economics.md) and used as a guideline. It does
not ensure the amount of stake allocated is valued more than the coins within
Serai's liquidity pools, as not possible to guarantee, but aims to limit the
coins/liquidity pools growth as would notably risk such a scenario occurring.
